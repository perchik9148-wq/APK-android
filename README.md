# Можно потратить

Нативное Android-приложение на Java, Android 8.0+, без сторонних библиотек, сети и регистрации.

## Возможности

Общий баланс в рублях, защищённый резерв, дата следующего дохода, расходы с описанием, пополнение баланса, будущие платежи, оплата и удаление платежей, отмена расходов и виджет домашнего экрана. Платежи и запланированные доходы можно повторять ежемесячно: после подтверждения они переходят на тот же день следующего месяца, а для 29–31 числа в коротком месяце используется последний день. Даты отображаются как `ДД-ММ-ГГГГ`; при вводе достаточно набрать восемь цифр, дефисы добавляются автоматически. Данные сохраняются локально между запусками. Удаление приложения удаляет данные; экспорт пока не реализован.

Свободно = баланс − резерв − неоплаченные платежи с датой не позднее следующего дохода (включая просроченные). Лимит = положительный свободный остаток / число календарных дней до дохода, округление вниз до копейки. День дохода не включается; при наступлении даты показывается предупреждение обновить план. Отрицательный остаток отображается как нехватка, дневной лимит равен нулю. Оплата платежа одновременно уменьшает баланс и убирает обязательство.

Виджет обновляется при изменении данных, системных событиях даты/времени и периодически (30 минут; Android может задерживать). Кнопка «Добавить расход» открывает форму приложения. Добавление: удержать главный экран → Виджеты → Можно потратить.

Пока нет уведомлений, банковской синхронизации и облачной копии. Повторяющаяся запись переносится после ручного подтверждения оплаты или получения; приложение не списывает и не начисляет деньги без подтверждения. История показывает последние 50 записей, остальные сохраняются локально.

## Сборка в текущей среде

```sh
./test.sh
./build.sh
```

Java 21 runtime, Eclipse ECJ 3.40.0 `/workspace/tools/ecj.jar`, Android API 35 `/workspace/tools/android-35/android.jar`, Build Tools 35 `/workspace/tools/android-15` (имя каталога в официальном архиве). Пути Android можно переопределить через `ANDROID_PLATFORM` и `ANDROID_BUILD_TOOLS`. Установка инструментов: `./setup-tools.sh`.

Результат: `build/mozhno-potratit.apk`. APK подписан локальным отладочным ключом. Сохраните `build/debug.keystore`, если хотите устанавливать следующие сборки поверх первой без удаления данных. Для публикации нужен отдельный постоянный release-ключ.

Проверены сборка, подпись и 14 проверок финансового расчёта. Запуск на устройстве/эмуляторе пока не проверен. Перед использованием для реальных денег проверьте ввод, перезапуск, оплату платежа и обновление виджета на телефоне.
